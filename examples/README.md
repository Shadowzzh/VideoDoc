# 示例产物

本目录存放 **VideoDoc 自己跑出来的成品文章**，用于展示工具的输出效果。

## 内容

- `2026-09-09-inkypi-eink-clock.md`：一篇完整产出的中文图文文章；
- `assets/`：该文章的配图，来自视频关键帧。

文章主题（树莓派墨水屏时钟）与 VideoDoc 项目本身无关——它只是拿一个真实视频跑完整条
流水线后的结果样本，用来说明「输入一个视频链接，最终能得到什么」。

## 查看方式

启动服务后访问 `/sample`，会以自包含页面渲染这篇文章（含配图）。

## 说明

这些文件不是项目文档，也不参与代码逻辑；`/sample` 路由只是把它们读出来渲染。
替换成你自己的产物同样可行。
